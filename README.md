### El deber contiene una serie de ejercicios de Programacion Orientada a Objetos incluyendo clases, objetos, encapsulamiento, herencias y polimorfismo
# Ejercicio 1: Clase Libro
# Objetivo
# Crear una clase libro que permita mostrar su informacion y determinar si es antiguo o reciente
# Atributos
# - Titulo
# - Autor
# - Año de publicacion
# - Numero de paginas
# Metodos
# mostrar_info()
# clasificar_libro()
# Ejercicio 2: Encapsulamiento con ProductoInventario
# Objetivo
# Gestionar productos del inventario protegiendo la informacion sensible mediante encapsulamiento
# Atributos
# - Codigo
# - Nombre
# - Precio (privado)
# - Stock (privado)
# Metodos
# - Consultar informacion
# - Aumentar stock
# - Disminuir stock
# - Cambiar precio
# Validaciones
# - El precio no puede ser negativo
# - El stock no puede ser menor que 0

# Clase base
# Vehiculo

# - Modelo
# - Año

# Auto
# Numero de puertas

# Objetivo
# Implementar diferentes metodos de pago utilizando el polimorfismo
